# V2Box subscription — Cloudflare Worker (с токеном)

Отдаёт подписку только по верному токену. Неверный токен, отсутствие токена или
чужой User-Agent → `404`, поэтому сканерам endpoint выглядит несуществующим.
Сами ссылки и токен хранятся в секретах Cloudflare — **не** в этом репозитории.

## Маршруты

| URL | Что отдаёт |
|-----|-----------|
| `GET /sub?token=SECRET` | Подписка в base64 (основной формат V2Box) |
| `GET /raw?token=SECRET` | Тот же список в plain text (фолбэк) |
| всё остальное | `404` |

## Деплой (5 минут)

Нужен аккаунт Cloudflare (бесплатного тарифа хватает) и Node.js.

```sh
cd cloudflare-worker

# 1. Установить и войти
npm i -g wrangler
wrangler login

# 2. Сгенерировать сильный токен (сохраните его — понадобится для URL подписки)
openssl rand -hex 24

# 3. Задать секреты (в публичный репозиторий они не попадают)
wrangler secret put TOKEN
#   -> вставьте токен из шага 2

wrangler secret put SUBSCRIPTION
#   -> вставьте ссылки (по одной на строку; пустые и // игнорируются).
#      Для одной ссылки просто вставьте её и Enter.
#      Для нескольких строк удобнее задать через дашборд:
#      Workers & Pages -> v2box-sub -> Settings -> Variables and Secrets.

# 4. (необязательно) пускать только клиентов V2Box по User-Agent
#    Раскомментируйте [vars] ALLOWED_UA = "v2box" в wrangler.toml

# 5. Задеплоить
wrangler deploy
```

После деплоя получите адрес вида `https://v2box-sub.<ваш-субдомен>.workers.dev`.

## Подписка в V2Box

Add Subscription → URL:

```
https://v2box-sub.<субдомен>.workers.dev/sub?token=ВАШ_ТОКЕН
```

Фолбэк (если сборка не парсит base64):

```
https://v2box-sub.<субдомен>.workers.dev/raw?token=ВАШ_ТОКЕН
```

> Токен — это фактически ключ доступа. **Не публикуйте** URL с токеном на
> странице `vpn.html` и нигде в открытом виде: у кого есть ссылка — у того есть доступ.

## Обновить список серверов

```sh
wrangler secret put SUBSCRIPTION   # вставить новый список
# либо отредактировать в дашборде — деплой не требуется, изменения применяются сразу
```

## Сменить/отозвать токен

```sh
wrangler secret put TOKEN          # новый токен -> старые ссылки перестают работать
```

## Проверка

```sh
# Верный токен -> 200 и base64
curl "https://v2box-sub.<субдомен>.workers.dev/sub?token=ВАШ_ТОКЕН"

# Без токена -> 404
curl -i "https://v2box-sub.<субдомен>.workers.dev/sub"

# Раскодировать и убедиться, что внутри ваши ссылки
curl -s "https://.../sub?token=ВАШ_ТОКЕН" | base64 -d
```

## Важно про безопасность

Прежние параметры (UUID, IP, `pbk`, `sni`) уже лежат в публичной истории git этого
репозитория. Токен на Worker закрывает **новый** endpoint, но не стирает старые данные
из истории и кэшей. Для реальной защиты **смените ключи Reality и UUID на сервере** —
тогда утёкшие ранее параметры станут бесполезны, а в `SUBSCRIPTION` положите уже новые ссылки.
